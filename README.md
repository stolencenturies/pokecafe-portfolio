# ☕ PokéCafé — My Digital World

A cozy, Pokémon-inspired developer portfolio built with HTML, CSS, and JavaScript.

🌐 **Live Website:** https://stolencenturies.github.io/pokecafe-portfolio/

📦 **Repository:** https://github.com/stolencenturies/pokecafe-portfolio

## ✨ About the Project

PokéCafé is a personal portfolio website designed as a cozy digital café. It showcases projects, skills, and personal information through an interactive interface inspired by Pokémon aesthetics and modern glassmorphism design.

The goal was to build a responsive, interactive website while practising front-end development fundamentals.

## 🚀 Features

- Dynamic project cards generated using JavaScript
- Interactive 3D flip-card effects
- Mouse-based card tilt effects
- Live project search
- Category-based filtering
- Project sorting
- Detailed project modal
- Conditional GitHub and Live Demo links
- Dynamic project count and results summary
- Reset filters functionality
- Keyboard-accessible modal controls
- Responsive layout for different screen sizes
- Reduced-motion accessibility support

## 💻 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/stolencenturies/pokecafe-portfolio.git
```

2. Open the project folder:

```bash
cd pokecafe-portfolio
```

3. Open `index.html` in your browser.

You can also open the folder in Visual Studio Code and use the Live Server extension.
